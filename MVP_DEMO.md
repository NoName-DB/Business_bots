# Business Bot MVP Demo — Этап 4

## 📋 Обзор MVP

Это рабочий макет бота для записи на услуги. Демонстрирует полный цикл: **запись → автоподтверждение → напоминания → отзыв**.

### ✅ Что входит в MVP

1. **Клиентский сценарий** (основное)
   - `/start` → меню
   - 💇 Услуги → выбор услуги
   - Выбор мастера (с рейтингом ⭐)
   - Выбор даты в формате ГГГГ-ММ-ДД
   - Выбор времени из доступных слотов
   - Ввод имени и телефона
   - **Подтверждение** → бронирование сохраняется в БД

2. **Автоматизация после бронирования**
   - ⏱️ **Grace Period**: 5 минут от конца записи + длительность сеанса
   - ✅ **Автозавершение**: статус `scheduled` → `completed` (после grace period + повторная проверка статуса)
   - 🔔 **Напоминания**: 24 часа и 1 час перед визитом (только для статуса `scheduled`)
   - ⭐ **Автозапрос отзыва**: после завершения предлагается оставить оценку 1-5 и комментарий

3. **Рейтинги**
   - Средний рейтинг мастеров (показывается при выборе мастера)
   - Средний рейтинг услуг (показывается в меню услуг)
   - Форматирование: `⭐ 4.7 (23)` или пусто если нет отзывов

4. **Админ-функции для демо** (базовые)
   - `/admin` → справка по командам
   - `/add_master name|bio|contact` — добавить мастера
   - `/add_service name|price|duration|description` — добавить услугу
   - `/set_schedule master_id|weekday(0-6)|start|end|interval_min` — расписание
   - `/list_bookings` — просмотр записей
   - `/complete_booking booking_id` — завершить запись и запросить отзыв
   - `/cancel_booking booking_id` — отменить существующую запись (бот удалит её при старте и очистит таймеры)
   - `/list_reviews` — все отзывы
   - `/avg_rating master|service|id` — средний рейтинг

### 🥶 Что заморожено (не удалено, но не используется в MVP)

- `❄️ /export_bookings` — экспорт записей в CSV (для аналитики, не нужно для демо)
- `❄️ /export_reviews` — экспорт отзывов в CSV
- `❄️ /add_exception` — управление исключениями в расписании мастера
- `❄️ /list_exceptions` — просмотр исключений
- `❄️ /edit_master`, `/edit_service`, `/delete_master`, `/delete_service` — редактирование и удаление (есть, но не критично для MVP)

## 🚀 Запуск MVP

### 1. Подготовка окружения

```bash
# Перейти в директорию проекта
cd /workspaces/Business_bots

# Установить зависимости (если ещё не установлены)
pip install -r requirements.txt

# Загрузить .env
# Убедиться, что есть:
# - BOT_TOKEN=<ваш telegram bot token>
# - ADMIN_IDS=<comma-separated list of admin IDs, например: 123456789,987654321>
```

### 2. Инициализация БД

```bash
# БД инициализируется автоматически при старте бота (в app/bot.py -> start_bot())
# Или можно вызвать явно:
python -c "import asyncio; from app.db import init_db; asyncio.run(init_db())"
```

### 3. Запуск бота

```bash
python app/main.py
```

Бот начнёт слушать Telegram обновления (polling mode). Выведет: `Bot started`

### 4. Тестирование в Telegram

1. Найти вашего бота в Telegram
2. Написать `/start`
3. Нажать кнопку 💇 **Услуги**
4. Пройти полный сценарий

## 🧪 Полный тестовый сценарий

### Шаг 1: Настройка данных (админ)

Отправить боту эти команды от админа:

```
/add_master Иван Иванов|Опытный мастер|+37061234567
/add_master Мария Петрова|Специалист ногтей|+37061234568

/add_service Стрижка|50.0|30|Классическая мужская стрижка
/add_service Маникюр|40.0|45|Классический маникюр

/set_schedule 1|0|09:00|18:00|60
/set_schedule 1|1|09:00|18:00|60
/set_schedule 2|0|10:00|17:00|45
/set_schedule 2|1|10:00|17:00|45
```

(Weekday: 0=пн, 1=вт, 2=ср, 3=чт, 4=пт, 5=сб, 6=вс)

### Шаг 2: Бронирование клиентом

1. `/start`
2. Нажать **💇 Услуги**
3. Выбрать **Стрижка** (услуга 1)
4. Выбрать **Иван Иванов** (мастер 1) — должно быть видно ⭐ рейтинг
5. Ввести дату: `2026-02-10` (завтрашний день от сегодня, или будущий рабочий день)
6. Выбрать время: `10:00`
7. Ввести имя: `Константин`
8. Ввести телефон: `+37061999999`
9. Нажать **Подтвердить**

✅ **Ожидание**: Бот ответит "✅ Запись подтверждена!" и запланирует:
- Auto-complete через ~30-35 минут (30 мин длительность + 5 мин grace period)
- Напоминание за 24 часа
- Напоминание за 1 час

### Шаг 3: Получение напоминаний

**За 24 часа перед визитом:**
```
Напоминание: У вас запись 2026-02-10 в 10:00 на услугу [название].
Мастер: [имя мастера]
```

**За 1 час перед визитом:**
```
Срочное напоминание: Через 1 час у вас запись!
```

### Шаг 4: Автозавершение и запрос отзыва

Когда наступит время завершения (end of slot + grace period):

1. Бот автоматически завершит запись (`status` = `completed`)
2. **Сразу же** отправит запрос отзыва:
   ```
   Спасибо, что выбрали нас! ⭐ Как прошёл ваш визит? Оцените от 1 до 5 и поделитесь впечатлениями.
   [Кнопки: 1 ⭐ 2 ⭐ 3 ⭐ 4 ⭐ 5 ⭐]
   ```

### Шаг 5: Оставить отзыв

1. Нажать **5** (или любую оценку)
2. Написать комментарий (или нажать кнопку "без комментария")
3. Бот подтвердит: "Спасибо за подробный отзыв! ⭐ Мы учтём ваши пожелания."

### Шаг 6: Проверить рейтинги (админ)

```
/avg_rating master|1
```

Ответ: `Мастер 1 — средняя оценка: 5.00 (1 отзывов)`

```
/list_reviews
```

Вывод всех отзывов.

## 🔍 Проверка логов и ошибок

### В консоли бота (при запуске `python app/main.py`):

Вы должны видеть логи вида:

```
auto_complete: booking_id=1, status_change=scheduled->completed, timestamp=2026-01-30T15:45:30.123456
reminder_sent: booking_id=1 kind=24h timestamp=2026-01-29T15:45:30.123456
reminder_sent: booking_id=1 kind=1h timestamp=2026-01-30T14:45:30.123456
```

### Критические ошибки (если видите):

- ❌ `KeyError: 'reminded_24'` или `'reminded_1'` — проблема с миграцией БД
- ❌ `IntegrityError: UNIQUE constraint failed` — попытка создать дубль записи (должна быть обработана `SlotTaken`)
- ❌ `AttributeError: 'sqlite3.Row' has no attribute 'get'` — проблема с доступом к полям БД (используйте `r['column']` вместо `r.get('column')`)

## 🐛 Известные ограничения MVP

1. **Нет UI для админа** (кроме команд) — все управление через текстовые команды
2. **Нет валидации дат в прошлом** — клиент может написать дату, которая уже прошла (бот не покажет слоты, но не выбросит ошибку)
3. **Ручные заявки (manual requests)** — есть функция fallback, если нет свободных слотов, но это не часть основного MVP потока
4. **Нет кэширования слотов** — каждый раз пересчитываются из расписания (нормально для малого числа пользователей)
5. **Часовые пояса** — всё в UTC по умолчанию (можно расширить позже)
